# Cologne-System

A perfume shopping system built with PHP and MySQL, featuring member management, purchasing functions, and an admin dashboard. The frontend is implemented with HTML, CSS, and jQuery.

---

## 🔧 Features

- 🧍‍♀️ Member registration and login
- 🛍️ Product browsing and perfume purchasing
- 🧾 Order placement and transaction history
- 🔐 Admin dashboard for managing members and products
- 🗄️ MySQL database integration

---

## 🧰 Tech Stack

| Category   | Technologies      |
|------------|-------------------|
| Frontend   | HTML, CSS, jQuery |
| Backend    | PHP               |
| Database   | MySQL             |
| Environment| Apache (Recommended: XAMPP/MAMP) |
